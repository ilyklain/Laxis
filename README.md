## Installation

```bash
npx tsx src/server.ts && npm run dev
```

server.ts starts the backend.

---

## Tech Stack

| Technology | Description |
| --- | --- |
| **TypeScript** | Used for Backend |
| **WebRTC** | Simple-Peer |
| **Socket.IO** | Used for WebSocket |
| **Stitch MCP** | Helps to build UI |
| **Node.js** | Signaling  |
| **Types** | Helps with peer maps |
